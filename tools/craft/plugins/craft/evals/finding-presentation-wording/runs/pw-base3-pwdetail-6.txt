**Members are not told what goes back in the case until two days before the return (C1)**

**Proposed outcome: fixed in the spec.**

You're asked whether the borrowing confirmation should list what goes back in the case. I recommend it should, so a member knows from the first day that the finder cap must come back with the telescope.

**Worst case:** the spec's confirmation email states only the loan and its return date (AC1). The case list arrives only in the reminder two days before the return date (AC5). A member who loses the finder cap during the loan learns it mattered only when that reminder arrives, or never if they miss it, and is then asked to replace it. The failure-cases reviewer reached the same case from another direction: a reminder sent to a mistyped address is never seen, and the case goes back without its cap. Two reviewers that could not see each other's work landed on the same missing cap.

Fix: `", and lists what goes back in the case: the telescope, its eyepieces, and the finder cap"` added to the end of the confirmation email in AC1, so the list arrives when the loan starts as well as two days before it ends. One caveat: the reminder already carries the list, so this closes the gap between borrowing and the reminder, not a total absence.

*Raised by: ease of use; supported by failure cases.*

**A loan holds a whole telescope for the full dates asked (C2)**

**Proposed outcome: needs a rewrite (`record-only`).**

You're asked whether a loan should be counted in nights rather than as one block from a start date to a return date. I recommend rewriting the borrowing criteria around nights, because the current shape lets one clear night hold the club's largest scope for a whole weekend.

**Worst case:** the spec ties a loan to a telescope and a start date (AC1). It then refuses any second request for that telescope and dates (AC2). A member who wants the big scope for Saturday night holds it from Friday to Monday. Another member, refused and offered the next free start date, waits weeks for a night the scope sat unused in someone's hallway. The spec also never says how the return date is set, since a member gives only a start date. So how long a loan lasts is undecided as well as too coarse.

Fix: members would book a telescope by the night and add nights as needed, so a one-night loan frees the scope for the rest of the weekend. This rewrites the Borrowing section, namely the four-field borrowing request (AC1), the one-member-at-a-time refusal (AC2) and the 48-hour cancellation (AC3), and in Returns and care the return-date check-in (AC4) and the two-day reminder (AC5).

  Prescription: replace "a start date" in AC1 with the nights wanted, and make AC2 refuse a night already taken and offer the next free night. Restate the cancellation cut-off in AC3, the check-in day in AC4 and the reminder timing in AC5 against the last night booked.

The reviewer rated its own confidence medium. The spec doesn't say how often a loan is for a single night, and that frequency decides how much the night-by-night shape is worth.

*Raised by: right problem.*

**A telescope left in the cupboard shows as free with no condition note (C3)**

**Proposed outcome: fixed in the spec.**

You're asked whether a returned telescope should stay off the calendar until someone has checked it. I recommend that, because otherwise the spec doesn't solve the scratched-mirror problem it opens with.

**Worst case:** the spec has the loan officer record the telescope as back with a condition note, and shows it as free from that day (AC4). That only works when the officer is there on the return date. A member who drops the scope in the cupboard on a day the officer is away leaves it showing as free with no note. The next member finds the scratched mirror, and nobody can say who had it. That is exactly the failure the Problem section names. With the spec stamped at production maturity, this is the failure path that matters most.

Fix:

    **AC4.** When a telescope comes back it shows on the club's loan calendar as returned and unchecked. It shows as free only from the day the loan officer records a note of its condition.

That replaces the current AC4. The officer no longer has to be present on the return date, and the scope stays unavailable until someone has checked it.

*Raised by: failure cases.*
