`fs-kiln/unload.py:3 — the cool-down hours come from a table keyed by kiln size, so a firing that ran hotter in the same kiln is marked ready too early`

Should each firing carry its own cool-down time instead of using one figure per kiln? I recommend yes, because as built a hotter firing goes on the board before it is safe to open.
