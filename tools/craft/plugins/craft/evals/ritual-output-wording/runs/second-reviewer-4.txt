- [Critical] None of the four tasks has a test contract. Concretely, task 2 and the plan's note break AC5. A return scanned after closing is stamped with the next morning's date. The 00:05 run then charges one more day, though AC5 says "Returning an overdue item stops the fee from growing the same day, even if the return is scanned after closing time." Nothing would catch it. Suggested: give each task a failing-first test contract. The first one returns an item at 18:30 after closing and asserts no fee is charged at the 00:05 run. Then test the fee cap at, just under and just over the replacement price (AC2), and the override at £10.00 and £10.01 (AC3).
- [Critical] The nightly job writes fees to the money records with nothing to make it safe or visible. Concretely, if it fails, is rerun, or overlaps the fee run at return time, a day is charged twice or not at all, and no one is alerted. Its first production run also charges every loan that is already overdue, with no dry run. Suggested: key each charge on (loan, date) so a rerun cannot double it. Log or alert on each run's success and the count of loans it touched. Before go-live, do a dry run that prints the first run's charges for a person to approve.
