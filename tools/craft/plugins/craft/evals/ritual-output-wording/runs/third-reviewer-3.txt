## Findings
- [Critical] No task has a test contract (tasks 1–4): nothing defines how fee arithmetic, the £10 threshold or the overdue flag is verified, so a wrong daily rate, a missed cap or an off-by-one at £10.00 ships unnoticed. Suggested: give each task a failing-first test. Task 2 needs a rate per category and a cap at replacement price minus a penny, exactly at it, and above it. Task 3 needs balances of £9.99, £10.00 and £10.01. Task 1 needs a loan due yesterday, one due today and one due tomorrow, using an injected clock.
- [Critical] The nightly job writes money with no sign it ran or ran only once: if the 00:05 job fails, nothing alerts anyone and that day's fees are silently never charged. If it reruns (retry, manual rerun, or overlapping the return-time recalculation in task 2), a day is charged twice and the ledger can't tell. Suggested: key each charge on (loan, date) so writes are idempotent, record each run (date, loans processed, fees written), and alert when a run is missing.
- [Important] Task 1 schedules the overdue flag for 00:05, but AC1 needs it on screen within one minute of rollover. Suggested: work out overdue at read time from due date vs. now, or drop the batch flag.
- [Important] The plan stamps after-closing returns with the next morning's date, which charges an extra day and breaks AC5. Suggested: store the physical scan time separately and work out fees from it. Pin this with a test of a return scanned at 23:59.
- [Important] No backfill plan for loans already overdue at go-live: the first run either charges weeks of back-fees in one go or charges nothing. Suggested: add a dry-run that previews charges before the first live run, and a gated, replayable backfill.
- [Important] A note on the borrower (task 3) doesn't capture which librarian granted the override, and no task shows it in the borrower's history (AC4). Suggested: store the override as a structured record (librarian ID, reason, time), and test the override path end to end.
- [Important] No task covers AC6 (reminders) or AC7 (the monthly report reconciling with the ledgers), so neither has any tests. AC7 needs a model for waived fees, which no task creates.
- [Minor] Returning an item while the nightly job is running can produce a partial or double charge. Run both on one per-loan transaction.
