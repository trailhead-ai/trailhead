# forge — structured planning and execution workflows

forge is an agent-native workflow plugin that gives Claude structured primitives
for test-driven development, assumption proving, code review, and planning. It
provides the council/circle design process and the subagent-driven development
flow.

**Standalone use:** forge stands alone — adopt it without lore or camp if you only
want the planning and execution workflows.

**Status:** populated by the Slice 5 move. See the trailhead root README for
install instructions.
