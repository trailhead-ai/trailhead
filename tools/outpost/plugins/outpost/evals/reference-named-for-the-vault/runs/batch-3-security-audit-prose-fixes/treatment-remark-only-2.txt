I still recommend **A, table rows**:
- **Tables:** people check invoices by reading down a column ("which line is the big one?", "is tax right everywhere?"), and a table lines every amount up with the totals. Ten or more lines still fit on one screen.
- **Cards:** they're about three times taller, so a 10-line invoice means scrolling, and amounts are harder to compare from line to line. Cards win in two cases: when the screen has to work on phones without a separate small-screen layout, or when lines carry extra detail like notes, attachments or approvals.

So the deciding question is: **does this screen need to work well on phones, or do individual lines carry more than the five basic fields?** If neither, I'd go with the table. If either one, cards (or a table that stacks into cards on narrow screens) are worth a closer look.
