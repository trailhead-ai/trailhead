# outpost eval corpus

Behavioural eval cases for outpost's own prose — the site daemon and the publish-site skill.

There are no cases yet. A case is a runner case, a directory with a `case.yaml`, run by
`claude plugin eval` and mapped to the prose it measures in an `eval-gate.json` here. The
case shape, how to write and run one, and the sandbox are in `docs/eval-protocol.md` —
read it before adding a case. Results go in `tools/outpost/MANUAL-EVAL.md`.
