```js
const STEPS = [
  { id: "business", label: "Business details", component: BusinessStep, isComplete: s => !!s.businessName },
  { id: "tax",      label: "Tax settings",     component: TaxStep,      isComplete: s => !!s.taxRegion },

];
```

The numbered list needs this to exist. It shows every step's name, number and state (done / current / not started) at once, so it needs all the steps up front. Wizards usually spread that across a `switch (step)` or a chain of `if`s with hard-coded "Next" targets, which only knows the current step. With the list in place:

- The side list is just `STEPS.map(...)`. Numbers come from position, and "done" comes from `isComplete`.
- Next and Back become `index ± 1` instead of hard-coded jumps.
- Clicking a finished step in the list to go back is a single check (allow it if every earlier step is complete).
- Adding or reordering steps later is a one-line change.
