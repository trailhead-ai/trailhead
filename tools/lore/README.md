# lore — agent-native project memory

lore is an agent-native knowledge-management plugin that gives Claude structured
primitives for decisions, dead-ends, deferred items, radar entries, and session
notes. It turns every project into a compounding knowledge store.

**Standalone use:** lore stands alone — adopt it without camp or forge if you only
want the knowledge-layer primitives.

**Status:** populated by the Slice 5 move. See the trailhead root README for
install instructions.
